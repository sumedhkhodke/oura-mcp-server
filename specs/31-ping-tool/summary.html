Spec #31: Add ping tool to Oura MCP server

Draft specification • 7 assumptions • 3 tasks

What: Add a simple, stateless MCP tool named ping that returns the server name, package version, and current UTC timestamp. The tool requires no arguments, does not call the Oura API or require credentials, and serves as a lightweight health check for MCP clients and a connection test for the Factorial pipeline.

Riskiest assumptions for review

A1: The response contains exactly three fields (server, version, time_utc), with no wrapper dict or metadata.
If wrong: Clients expecting a simple object get nested data; structural change to response and all tests required.
A2: The time_utc field uses Python's isoformat() default format (e.g., 2026-10-28T16:30:45.123456+00:00), not Z suffix.
If wrong: Clients parsing Z suffix will fail; timestamp format and AC5 change.
A3: The tool will never raise an exception and has no error path.
If wrong: A test expects error-case coverage; tool remains trivial with only a happy path.

Implementation overview

The ping() function is 3 lines of code, added before the run() function in server.py:

@mcp.tool
async def ping() -> dict[str, Any]:
    """Ping the server: returns server name, version, and current UTC time."""
    from datetime import datetime, timezone
    return {
        "server": mcp.name,
        "version": __version__,
        "time_utc": datetime.now(timezone.utc).isoformat(),
    }
